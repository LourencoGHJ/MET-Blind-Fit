# Changelog

## 0.3.0+3
- Preferências de acessibilidade persistidas em SQLite.
- Texto ampliado aplicado globalmente.
- Opção de fundo de alto contraste aplicada globalmente.
- Ecrã de acessibilidade dedicado, acessível a partir da barra superior e do perfil.
- API mock com operações de teste para reservas, amizades, sessões e incidentes.
- Estado JSON do backend de testes separado dos dados seed.
- Testes smoke da API e script de compilação APK com análise/testes.
- Documentação revista para distinguir funcionalidades reais de simulações.

## 0.3.1+4
- Reescrita estruturada do ecrã principal para eliminar blocos Dart com sintaxe malformada.
- Fluxos de descoberta, detalhe e reserva, comunidade/QR, preferências, dashboard e corrida demonstrativa reorganizados.
- Script APK agora interrompe logo com instruções claras quando falta Android SDK.
- Testes da API deixam de emitir ResourceWarning por HTTPError não fechado.
