# MET Blind Fit — Cenários de utilização

## 1. Encontrar um guia

Um corredor cego ou com baixa visão consulta os guias disponíveis,
analisa os perfis e solicita acompanhamento para uma corrida.

Os participantes combinam o horário, o percurso e as condições
necessárias antes de confirmar a atividade.

## 2. Participar como guia

Uma pessoa que pretende acompanhar corredores consulta pedidos
compatíveis e manifesta disponibilidade para uma atividade.

A plataforma deve permitir que ambas as partes conheçam as
informações relevantes antes de aceitarem o acompanhamento.

## 3. Organizar uma corrida de grupo

Os participantes organizam uma atividade conjunta, consultam
o ponto de encontro, o horário e a lista de participantes confirmados.

A organização deve considerar as necessidades de acessibilidade
e as responsabilidades de acompanhamento.

## 4. Criar uma ligação através de QR

Dois participantes podem utilizar um código QR para facilitar
a ligação entre os respetivos perfis, com confirmação da ação
e respeito pela privacidade.

## 5. Acompanhar uma atividade

A visão do projeto contempla ferramentas de coordenação durante
a corrida, incluindo partilha de localização mediante autorização.

Esta funcionalidade necessita de implementação e validação antes
de poder ser considerada operacional.

## 6. Confiança e segurança

A plataforma deverá prever permissões adequadas, proteção dos dados
e mecanismos de verificação de guias e supervisores.

O protótipo não substitui a validação de identidade, testes reais
de acessibilidade ou procedimentos de segurança.

## Estado

Estes cenários descrevem o comportamento pretendido para o MET Blind Fit.
Não representam uma garantia de que todas as funcionalidades estejam
implementadas ou prontas para utilização real.
